FocusTube

Safari에서 YouTube의 방해 요소를 숨겨 줍니다.
Hide YouTube distractions in Safari.

확장 프로그램 켜기 Enable the extension

  1. 설정 앱 → 앱 → Safari → 확장 프로그램Settings → Apps → Safari → Extensions
  2. FocusTube를 켭니다.Turn on FocusTube.
  3. youtube.com 접근을 허용으로 설정합니다.Set youtube.com access to Allow.

사용 방법 How to use

  1. Safari에서 youtube.com을 엽니다.
  2. 주소창의 확장 프로그램 아이콘(퍼즐 모양)을 누르고 FocusTube를 선택합니다.
  3. 숨길 요소, 필터, 집중 타이머, 프리셋을 설정합니다.

YouTube 앱에는 적용되지 않으며 Safari의 youtube.com / m.youtube.com에서만 동작합니다.
Works only on youtube.com in Safari, not in the YouTube app.
